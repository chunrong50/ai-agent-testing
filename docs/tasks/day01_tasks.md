思考题：

假设用户问：
我的订单 A10086 已经支付成功了吧？

模型直接回答：
是的，您的订单已经支付成功。

但是实际上系统没有查询任何订单数据。

请问：
1. 这个回答在文本层面是否合理？
2. 在业务测试层面是否通过？
3. 你应该增加什么测试机制？
这个问题很重要，后面我们会通过 Agent Trace 和 Tool Calling 测试来解决。
